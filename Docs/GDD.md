# Suika Game — Game Design Document

## 1. 게임 개요

| 항목 | 내용 |
|------|------|
| 장르 | 물리 기반 퍼즐 / 캐주얼 |
| 한 줄 요약 | 과일을 떨어뜨려 같은 과일끼리 합쳐 수박을 만드는 고득점 게임 |
| 플랫폼 | Unity 2D (PC) |
| 승리 조건 | 없음 (무한 모드, 고득점 추구) |
| 패배 조건 | 과일이 컨테이너 상단 경계를 초과하면 게임오버 |

### 코어 루프

```
과일 선택(랜덤 예고) → 마우스로 위치 조준 → 클릭으로 드롭
→ 물리 낙하 · 구르기 → 같은 과일 충돌 → 합체 → 다음 레벨 과일 생성
→ 점수 획득 → 반복 (컨테이너 넘치면 게임오버)
```

---

## 2. 핵심 메커닉

### 드롭
- 마우스 X 위치로 드롭 위치 결정 (컨테이너 좌우 벽 안으로 클램프)
- 드롭 가능 과일: **레벨 0~4** (체리·딸기·포도·귤·감) 중 랜덤
- 드롭 후 **약 0.5초 쿨타임** 뒤 다음 과일 생성
- 상단에 **다음 과일 미리보기** 표시 (반투명)

### 충돌 & 합체
- 2D 물리 엔진(Rigidbody2D + CircleCollider2D) 사용
- **같은 레벨** 과일 두 개가 충돌하면 합체
- 합체 위치: 두 과일의 중간 지점
- 합체 후 다음 레벨 과일 1개 생성
- 최고 레벨(수박, Lv.10)은 합체 없음

### 게임오버
- DeathZone(컨테이너 상단 경계선)에 과일이 **일정 시간 이상** 접촉하면 게임오버
- 드롭 직후 생성된 과일은 판정 제외 (안착 대기 시간 필요)

## 3. 과일 단계

| Lv | 이름 | 합체 점수 | 반지름(Unity unit) | 색상(참고) |
|----|------|----------|--------------------|-----------|
| 0  | 체리 | 1 | 0.30 | 빨강 |
| 1  | 딸기 | 3 | 0.40 | 분홍빨강 |
| 2  | 포도 | 6 | 0.55 | 보라 |
| 3  | 귤(데코폰) | 10 | 0.70 | 주황 |
| 4  | 감 | 15 | 0.85 | 진주황 |
| 5  | 사과 | 21 | 1.00 | 빨강 |
| 6  | 배 | 28 | 1.15 | 연두 |
| 7  | 복숭아 | 36 | 1.30 | 살구 |
| 8  | 파인애플 | 45 | 1.50 | 노랑 |
| 9  | 멜론 | 55 | 1.70 | 연초록 |
| 10 | 수박 | 66 | 2.00 | 초록 |

> 합체 점수는 삼각수 공식: `Lv(Lv+1)/2 × 1` 기반 (원작 근사값)

## 4. 점수 & 승패 규칙

- **점수 획득 시점**: 합체가 발생할 때마다 해당 결과 레벨의 점수를 즉시 추가
- **점수 표시**: 화면 상단 중앙
- **최고 점수**: 세션 내 갱신, 로컬 저장 (PlayerPrefs)
- **게임오버**: 씬 정지 후 Game Over 패널에 최종 점수 표시
- **재시작**: 버튼 클릭 시 씬 리로드

## 5. 화면 & UI 구성

```
┌─────────────────────────────┐
│       Score: 0000           │  ← 상단 중앙 (ScoreText)
│   [Next: 🍇]                │  ← 우측 상단 (NextFruitPanel)
│                             │
│   ┌─────────────────┐       │
│   │  (드롭 라인)     │  ← 빨간 점선
│   │                 │
│   │   컨테이너      │  ← 좌우 벽 + 바닥
│   │   (물리 영역)   │
│   │                 │
│   └─────────────────┘
└─────────────────────────────┘
```

| UI 요소 | 위치 | 내용 |
|---------|------|------|
| ScoreText | 상단 중앙 | 현재 점수 |
| NextFruitPanel | 우측 상단 | 다음 과일 미리보기 |
| DropIndicator | 컨테이너 상단 드롭 위치 | 세로 점선 |
| GameOverPanel | 화면 전체 오버레이 | "GAME OVER" + 점수 + 재시작 버튼 |

## 6. 톤 & 분위기

| 항목 | 방향 |
|------|------|
| 색감 | 따뜻한 크림/베이지 배경, 과일 고유 채도 높은 단색 |
| 아트 스타일 | 단순 원형 + 텍스트 레이블 (프로토타입), 이후 스프라이트 교체 가능 |
| BGM | 경쾌하고 귀여운 캐주얼 루프 |
| SFX | 드롭 효과음, 합체 팝 효과음, 게임오버 효과음 |

---

## 7. 기술 스택

- **엔진**: Unity 2022+ (2D URP)
- **물리**: Physics2D (Rigidbody2D, CircleCollider2D)
- **UI**: Unity uGUI (Legacy Text → 추후 TextMeshPro 교체 검토)
- **스크립트**: C# — `Fruit.cs`, `GameManager.cs`, `DeathZone.cs`
- **저장**: PlayerPrefs (최고 점수)
